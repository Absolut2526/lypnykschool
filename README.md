# Офіційний веб-сайт Липницького ЗЗСО І–ІІ ступенів (1–9 класи)

Сучасний, адаптивний та автономний веб-портал Липницького закладу загальної середньої освіти І–ІІ ступенів (1–9 класи) Рава-Руської міської ради Львівського району Львівської області.

## 🌟 Особливості сайту:
- Повний архів шкільних новин та подій (170+ матеріалів) із локальними світлинами та відео.
- Окремі розділи: Про школу, Прозорість, Батькам, Навчальний процес, Атестація, Психологічна служба, Галерея, Контакти.
- Вбудована система перегляду офіційних документів (Modal Reader) без залежності від сторонніх сервісів.
- Адаптивний сучасний дизайн (Glassmorphism, зручне мобільне меню, Lightbox галерея).

## 🚀 Запуск:
Відкрийте `index.html` у будь-якому сучасному веб-браузері.
